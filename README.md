# TokoApp — Aplikasi Pencatatan Produk Toko (JavaFX GUI)

**TokoApp** adalah aplikasi desktop berbasis JavaFX yang dirancang untuk mengelola data produk toko secara efisien. Aplikasi ini menerapkan pola arsitektur **MVC (Model-View-Controller)** untuk memisahkan logika data, antarmuka pengguna (UI), dan navigasi halaman.

## Fitur Utama

- **Daftar Produk (Table View)**: Menampilkan seluruh data produk toko secara terstruktur dalam bentuk tabel.
- **Detail Produk**: Menampilkan rincian informasi produk (Kode, Nama, Kategori, Harga) beserta foto produk pendukung.
- **Form Input / Edit Produk**: Memungkinkan penambahan produk baru maupun pembaruan data produk yang sudah ada.
- **Navigasi Halaman**: Peralihan antarmuka yang mulus antar-tampilan menggunakan `Navigator`.
- **Format Mata Uang**: Format harga produk otomatis disesuaikan ke dalam format mata uang Rupiah (`Rp`).

- ## Cara Menjalankan Project
- 1. Clone Repository
     - git clone [https://github.com/resthyaraedhina-ui/Project-JavaFX-GUI---Level-2.git](https://github.com/resthyaraedhina-ui/Project-JavaFX-GUI---Level-2.git)
  2. Buka Project
     - Buka IDE NetBeans (atau IDE pilihanmu).
     - Pilih File > Open Project, lalu arahkan ke folder TokoApp.
  3. Build & Run
     - Klik kanan pada project TokoApp > Clean and Build.
     - Jalankan file MainApp.java atau klik tombol Run Project (F6).
